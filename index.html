02 / READ THE MODEL BEFORE THE NUMBER

THE HONESTY LAYER

Distance uses a logarithmic scale because a linear one would compress every planet into a single pixel. The route begins at Earth's orbit; the Sun-to-Earth launch leg is deliberately outside the scale.

Measured means a speed was recorded. Counterfactual means that speed is frozen forever to expose scale—not predict a mission. Design study preserves a published profile. Fiction stays labelled, and ships with no comparable linear speed receive no invented arrival time.

The heliopause is represented by Voyager 1's crossing near 122 AU, not a fixed spherical wall. The Oort Cloud has not been directly observed; its 100,000 AU outer edge is a conservative model boundary, not a wall a spacecraft can photograph while crossing.
