    02 / READ THE MODEL BEFORE THE NUMBER

    THE HONESTY LAYER

    The map never switches to a logarithmic ruler: every object uses the same AU-per-pixel scale. Its locked camera automatically expands at planetary, heliopause, Inner Oort, Outer Oort and interstellar boundaries. The view changes; the proportions never do.

    Positions use a top-down J2000 ecliptic projection. The map draws the supplied x and y coordinates directly, so real JPL trajectories keep their observed planar shape; the out-of-plane z coordinate remains in the selected-object readout. Like any flat star map, it is an orthographic view of three-dimensional space rather than a claim that every object lies on one sheet.

    Measured means a speed was recorded. Counterfactual means that speed is frozen forever to expose scale—not predict a mission. Design study preserves a published profile. Fiction stays labelled, and ships with no comparable linear speed receive no invented arrival time.

    The heliopause is represented by Voyager 1's crossing near 122 AU, not a fixed spherical wall. The Oort Cloud has not been directly observed; its 100,000 AU outer edge is a conservative model boundary, not a wall a spacecraft can photograph while crossing.
